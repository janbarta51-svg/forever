# WoW Forever — Warrior Field Guide

Static, Czech-language companion for WoW Forever Protection Warrior levels 1–30. Reuses visual style from `janbarta51-svg/wow.field.guide`.

## Sections
Warrior (level-aware consumables/gear), Food buffy, Dungeon group (party buffs and crowd control), Campfire & profese, Užitečné linky and CMS.

## Running
Open `index.html` in a browser, or host on GitHub Pages. No build step.

## CMS
Open `cms.html` to manage `links.json`: either download the JSON and commit manually or publish with a fine-grained GitHub token that has `Contents: read/write` permission for only this repository. The token is used per session and is not saved.

## Tooltips
Hover over linked item/spell names for Wowhead-powered tooltips when available. A local accessible fallback tooltip is displayed when remote script is blocked or an exact Wowhead ID has not been verified.

This is an unofficial fansite. Data for WoW Forever may be updated by game patches. See source links in UI.
